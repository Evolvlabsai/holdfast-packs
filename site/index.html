Holdfast packs

The signed content catalog for Holdfast, an offline survival and emergency-prep app. This page exists so the catalog has a stable address; it is not a download site.

Files

  • manifest.json The catalog. Every pack the app may install, with a size and a SHA-256 for each file.
  • manifest.json.sig Detached Ed25519 signature over the manifest's exact bytes, base64.
  • schema/manifest.schema.json JSON Schema for the catalog.
  • news.json The News & tips feed shown on the app's Home screen. Images live under news/img/.
  • news.json.sig Detached Ed25519 signature over the feed's exact bytes, same key as the manifest.
  • schema/news.schema.json JSON Schema for the feed.

Trust model

  • The app carries one Ed25519 public key, compiled in. A catalog whose signature does not verify is ignored and the last good one is kept.
  • Every file in the catalog carries a size and a SHA-256. A download that does not match is discarded, whichever mirror served it.
  • The signing key lives only in this repository's CI secrets, and a manifest is signed only after a human merges the change.
  • No accounts, no analytics, no server. The app's only network calls are fetching this catalog and the News & tips feed, and downloading packs.

Licences

Each pack records its own license and attribution in the catalog. The material comes from US federal agencies (public domain), OpenStreetMap (ODbL), Wikipedia and Stack Exchange (CC BY-SA) and iFixit (CC BY-NC-SA). Credits are shown in the app, and on the map for map data.
