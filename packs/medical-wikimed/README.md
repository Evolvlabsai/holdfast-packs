# medical-wikimed — WikiMed medical encyclopedia

About 340,000 medical articles from English Wikipedia (WikiProject Medicine),
packaged by Kiwix as a ZIM file. Text only ("nopic" edition), about 1 GB.

- **Hosting:** linked. The app downloads it straight from download.kiwix.org.
- **Format:** `zim`, read on the phone by `Holdfast.Core.Zim.ZimArchive`.
- **Licence:** CC BY-SA 4.0 — Wikipedia contributors; packaged by Kiwix.
- **Needs:** app 0.2.0 or later (`minAppVersion`), the first build with the ZIM reader.
- **Cadence:** Kiwix republishes about every six months; re-point with
  `update_manifest.py --from-url`.

This is an encyclopedia, not reviewed medical guidance. The curated, reviewed
first-aid content lives in the `medical` and `manuals` packs.
